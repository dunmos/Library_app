
The Masomo Bora Library system is a simple web-based application built using HTML, CSS, and JavaScript. It allows users to manage a personal book collection by adding books, viewing book details, tracking reading progress, and removing books from the library.

This project was developed as part of The Odin Project – JavaScript curriculum to practise JavaScript objects, constructors, prototypes, arrays, and DOM manipulation.

Features

Add New Books: Add books through a dialog form by entering the title, author, number of pages, and reading status.

Display Books: View all added books in individual cards.

Unique Book IDs: Each book is assigned a unique identifier using crypto.randomUUID().

Track Reading Progress: Mark books as read or not read.

Color-Coded Status: Read books are displayed in green, while unread books are displayed in red.

Change Read Status: Toggle a book's reading status using a button on its card.

Remove Books: Remove individual books from the library.

Dynamic Display: The library automatically updates whenever a book is added, removed, or its reading status changes.

Technologies Used

HTML5 – Application structure and dialog form.

CSS3 – Styling, layout, and responsive design.

JavaScript (ES6) – Application logic and interactivity.
